一、引言

《nege》（以下简称"本游戏"）是由耄耋厂开发并运营的单机游戏。本游戏无需联网即可完整运行，我们不要求您注册账号，也不以提供服务为目的收集您的个人信息。

我们高度重视您的隐私保护。本政策依据《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》《儿童个人信息网络保护规定》以及 GB/T 35273—2020《信息安全技术 个人信息安全规范》等法律法规与国家标准制定，旨在向您说明我们在您使用本游戏过程中如何处理个人信息，以及您享有的相关权利。

请您在使用本游戏前仔细阅读并理解本政策。如您不同意本政策的任何内容，请立即停止安装或使用本游戏。

二、我们收集和使用哪些信息

1. 基本原则：最小必要、能不收集就不收集

在默认情况下，本游戏不会收集、存储或上传任何可识别您个人身份的信息（包括姓名、手机号、邮箱、设备标识符、位置信息、通讯录等）。

2. 仅在本地产生且不上传的数据

数据类型：游戏存档、进度、设置
用途：保存您的游玩进度与偏好
存储位置：您的设备本地存储
是否上传：否

数据类型：崩溃日志、性能数据
用途：用于排查故障、优化游戏（仅在您主动提交时）
存储位置：仅保存在本地，由您决定是否发送给我们
是否上传：否（除非您主动发送）

数据类型：系统语言、屏幕分辨率
用途：适配界面显示与输入方式
存储位置：仅运行时读取，不记录
是否上传：否

3. 需要联网的功能（如有）

若未来版本增加需联网的功能（例如云存档、在线更新、排行榜），我们将单独弹窗提示，明确告知所需信息类型与用途，并在取得您的同意后才会开启。您随时可在设置中关闭该功能，关闭后不影响单机内容的正常使用。

三、Cookie 及同类技术

本游戏不使用 Cookie、Web Beacon、SDK 或任何追踪技术，不绘制用户画像，也不进行任何形式的行为追踪。

四、第三方 SDK 与广告服务

本游戏未集成任何第三方 SDK、广告插件或数据统计组件，因此不存在向第三方共享个人信息的情形。

若未来引入第三方服务，我们将重新评估其合规性，在本政策中列出其名称、收集目的与联系方式，并另行征得您的同意。

五、我们如何共享、转让、公开披露个人信息

除以下情形外，我们不会与任何第三方共享、转让或公开披露您的个人信息：

1. 事先获得您的明确同意；
2. 根据法律法规规定，或应行政、司法机关依法提出的要求；
3. 为维护本游戏的安全稳定运行，或保护我们及用户的合法权益所必需。

六、我们如何保护您的信息

- 游戏存档等本地数据仅保存在您的设备上，我们无法访问、读取或控制；
- 若您通过邮件等方式向我们提供反馈或崩溃日志，我们将采取合理的加密与访问控制措施予以保管；
- 我们会定期审查内部的数据处理实践，防止信息遭到未经授权的访问、泄露或损毁。

提示：由于本地存档保存在您的设备中，请您妥善保管设备并自行备份重要存档。设备丢失、卸载游戏或清除数据可能导致存档永久丢失，对此我们无法恢复。

七、您的权利

依据《个人信息保护法》，您对个人信息的处理享有以下权利：

- 知情权与决定权：有权了解我们如何处理您的信息，并有权拒绝或限制处理；
- 查阅、复制、更正、删除权：本地存档可由您自行在游戏内或设备文件管理中查看、修改或删除；
- 撤回同意权：对于未来可能新增的联网功能，您可随时在设置中关闭；
- 注销权：本游戏无账号体系，直接卸载即可；
- 投诉举报权：如您认为我们的处理侵犯了您的合法权益，可向网信、工信等主管部门投诉，或依法向人民法院提起诉讼。

您可以通过本政策第十一条列明的联系方式行使上述权利。我们将在 15 个工作日内予以答复。

八、未成年人保护

本游戏不针对未满十四周岁的儿童设计，也不主动收集儿童个人信息。我们建议未成年人在监护人陪同下使用本游戏，并请监护人妥善管理设备的存储权限与联网权限。

若我们知悉自己收集了儿童个人信息，将在核实后尽快删除。

九、个人信息的跨境传输

本游戏不涉及个人信息出境，亦不会将任何信息传输至中国大陆境外。

十、本政策的更新

如本游戏功能或处理方式发生变更，我们将通过游戏内公告、官网或应用商店页面等适当方式通知您，并更新本政策顶部的"生效日期"。重大变更（例如新增联网功能或引入第三方服务）时，我们将以显著方式再次征得您的同意。
